# YouTube Engagement Analysis 📊

A Power BI capstone project analyzing YouTube channel performance metrics 
to uncover viewer behavior patterns and engagement drivers.

## 🎯 Objective
To analyze a YouTube dataset and provide actionable recommendations for 
content creators and marketers by identifying trends in uploads, views, 
subscribers, and channel performance.

## 📁 Files
- `Project.pbix` — Power BI report file
- `Binnika_Capstone_Project.pdf` — Dashboard screenshots

## 🛠️ Tools Used
- Power BI (DAX, Power Query, Data Cleansing)

## 📊 Key Visuals Built
- KPI Cards: Max uploads (301K), Min view rank (1), Avg views last 30 days (175.61M)
- Line chart: Top channels crossing 2 lakh uploads
- Radar chart: Channel type vs channel rank
- Packed bubble chart: Category-wise subscribers
- Decomposition tree: Rank-wise category breakdown
- Table visual: Channel type vs Views per Subscriber

## 💡 Key Insights
- Entertainment and Music dominate with 5.1B+ subscribers each
- Total uploads across all channels: 9 billion
- Entertainment leads rank-wise with 241 ranked channels
- Views per Subscriber highest in Entertainment (137K) and Music (123K)
